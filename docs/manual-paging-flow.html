UniversalPaging — MANUAL mode flow

1. Construct — new UserPager(new DBQuery(host,user,pass,db))
↓
2. Set SQL — setSQLStatement('SELECT ... FROM pengguna ORDER BY ...') (no LIMIT)
↓
3. Configure — setPagingProperty(MANUAL, $perPage, false, $blind)
↓
4. Inject totals (optional) — setPageProperty($info) with totalRow/totalPage/memTableName
↓
5. Render one page — startPaging($currentPage) → renderPaging($page)
↓
6. Your code runs — performTaskOnEachPage($q, $start, $end) processes rows; handleTaskOnNoPaging() if empty
↓
7. UI — read getPagingInfo() for prev/next links; no recursion, no sleep

Blind mode (MANUAL + blind)

How it works

  • No upfront row count.
  • Pages until empty result.
  • Sets lastPage = 1 on empty.

Frontend signal

  • hasNext = rows.length === perPage && last_page !== 1
  • No "page X of N" (totals = 0).

Safety

  • Cap: BLIND_MAX_PAGES = 100.
  • Use for log/audit trails.

PHP endpoint

$page = max(1, (int)($_GET['page'] ?? 1)); $perPage = max(1, (int)($_GET['per_page'] ?? 10)); $blind = filter_var($_GET['blind'] ?? false, FILTER_VALIDATE_BOOLEAN); $pager = new UserPager($db); $pager->setSQLStatement('SELECT ... FROM pengguna ORDER BY ...'); $pager->setPagingProperty(IPagingType::MANUAL, $perPage, false, $blind); $pager->startPaging($page); echo json_encode([ 'page' => $page, 'per_page' => $perPage, 'blind' => $blind, 'rows' => $pager->rows, 'info' => ['total_row' => ..., 'total_page' => ..., 'last_page' => $pager->getLastPageStatus()], ]);
